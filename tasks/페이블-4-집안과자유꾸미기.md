# Fable 작업 4 — 집 안 들어가기, 자유 배치, 직접 그린 그림 (제안, 2026-11-15)

사용자 요청: "6x6 칸에 고르는 방식 말고 직접 설치하고, 직접 그린 그림을 넣을 수 있으면 좋겠다. 동물의 숲처럼 집 안에도 들어갈 수 있게."
씬(`src/scene/**`) 작업이 먼저 필요하다. 앱/서버/DB(Opus)는 아래 인터페이스가 생기면 붙인다. 먼저 CLAUDE.md 와 README-scene.md 를 읽는다.

## 1. 집 안 들어가기
- 걷기 모드에서 내 집(또는 남의 집) 문 앞에서 "들어가기" → 집 안 방 하나(예: 8x8 칸, 벽 2면 + 바닥)로 바뀐다. 동물의 숲처럼 위에서 비스듬히 보는 시점.
- 남의 집은 구경만, 내 집은 꾸미기 가능.
- 새 함수 (기존 함수는 바꾸지 않는다)
  - `enterHouse(houseNo, interior: InteriorItem[], wallpaper?: string, floor?: string)` / `exitHouse()`
  - `onDoor(cb(houseNo | null))` : 문 앞에 가면 알림 (앱이 "들어가기" 버튼을 띄운다)
  - `onExitHouse(cb)` : 문으로 나가면 알림
- 집 안은 한 번에 한 집만 그린다(성능). 다른 유저 실시간은 집 안에서는 끄거나 같은 집 안 사람만(앱이 방 'house:12' 로 붙는다).

## 2. 자유 배치 (마당 + 집 안)
- 칸이 아니라 손가락으로 끌어서 놓고 돌리는 방식. 겹치면 빨간색으로 표시하고 못 놓는다.
- 새 타입 (Opus 가 `src/shared/types.ts` 에 추가할 예정. 모양 제안)
  - `PlacedItem = { id: string, type: string, x: number, z: number, rotY: number, drawingId?: string }` (x, z 는 마당/방 안 좌표, 미터 단위 소수)
- 새 함수
  - `setYardItemsFree(houseNo, items: PlacedItem[])` (기존 `setYardItems` 는 그대로 둔다)
  - `startPlacing(type | itemId)` / `stopPlacing()` / `onPlace(cb(item: PlacedItem))` / `onPick(cb(itemId))` : 꾸미기 모드에서 끌어 놓기
- 아이템 종류를 늘리기 쉽게: 모양 하나에 이름만 붙이면 되는 구조(액자, 러그, 침대, 책장, 창문, 벽지 등).

## 3. 직접 그린 그림
- 그림은 **32x32 픽셀, 16색 팔레트** (예전 기획대로. DB 에 가볍고 부적절한 그림 관리도 쉽다). 그림 하나 = 512바이트.
- 쓰이는 곳: 액자(벽), 간판, 러그(바닥), 옷(나중에).
- 새 함수: `setDrawings(drawings: { id, pixels: string(base64 512바이트), palette: string[16] }[])` → 텍스처로 만들어 `drawingId` 가 있는 아이템에 붙인다. 텍스처는 32x32 로 아주 작게, 가까운 집 것만.
- 그리기 화면(픽셀 편집기)은 Opus 가 앱에서 만든다.

## 성능 메모
- 마당 자유 배치 아이템은 지금처럼 종류마다 InstancedMesh. 그림 붙은 아이템은 텍스처가 달라서 따로 그리므로 가까운 집만.
- 집 안은 들어갔을 때만 만든다.
