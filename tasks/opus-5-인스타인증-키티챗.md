# 작업: 인스타 인증 (키티챗 팔로워 암호 + 댓글 확인)

새 채팅에서 이 파일을 먼저 읽고 시작한다. (2026-11-16 결정, 2026-11-17 흐름 바꿈 + 구현)

## 결론 (왜 이 방식인가)
- 사용자는 **사업자 등록을 할 수 없다** → Meta 앱 심사(고급 권한) 불가 → 아무 유저의 DM 을 받는 웹훅은 못 쓴다.
- 매니챗 Pro 는 외부 요청(웹훅) + 팔로워 조건이 되지만 **비싸서 제외**.
- **키티챗 Pro ($22/월)** 로 결정. 인스타 계정 2개(고양이섬 + 드럼) 연결 가능.
- 키티챗은 외부 API/웹훅을 못 부른다 → DM 에 **사람마다 다른 코드를 넣을 수 없다**. 모두 같은 "팔로워 암호"만 넣는다.
  (참고: @mbtiplanet.kr 은 DM 으로 사람마다 다른 코드를 준다. 키티챗으로는 그 방식이 안 된다)

## 키티챗 상담 확인 내용 (사람 상담원 답변 기준)
- ✅ 인스타 계정 2개 연결 (Pro) / ✅ 릴스 댓글 자동 DM / ✅ 팔로워 여부에 따라 다른 버튼 DM
- ✅ 댓글 키워드 조건 / ✅ 모든 게시물에 한 번에 / ✅ DM 무제한
- ❌ 외부 주소로 API/웹훅 부르기 없음
- 미확인(가입 후 직접 시험): 팔로우 후 버튼을 다시 누르면 팔로워 메시지가 나오는지 / 문구 수정이 바로 반영되는지 / 같은 사람이 여러 번 댓글 달면 DM 이 매번 가는지.

## 유저 흐름 (2026-11-17 사용자와 확정)
1. @goyangi.seom 팔로우
2. 릴스에 "입주" 댓글
3. 키티챗 DM 버튼 → 팔로워면 **팔로워 암호**
4. 사이트에 **인스타 아이디 + 암호** (+ 닉네임, 지역, 고양이, 집)
5. 서버가 그 아이디로 **24시간 안에 단 댓글**이 있는지 확인 → 가입 (`houses.ig_id`, `verified=1`)
   - 못 찾으면 그 자리에서 댓글을 한 번 더 읽는다(모든 사람 합쳐 20초에 한 번).

## 도용 막기 (암호가 모두 같아서 생기는 빈틈)
- 남이 내 댓글을 보고 내 아이디 + 암호로 먼저 가입할 수 있다. 유저가 할 일을 늘리지 않는 장치:
  1. 기기 하나에 집 하나 (localStorage `ci_dev` → `signup_log.device`)
  2. 24시간 안의 댓글만 인정
  3. **되찾기**: 사이트가 준 6글자 코드를 내 아이디로 댓글 → 확인되면 그 집으로 로그인, 다른 로그인 모두 끊김 (`#/reclaim`)
  4. **신고 버튼** (`#/report`, 집 팝업의 "신고하기", 설정) → 관리자 화면에서 처리 / "인스타 아이디 비우기"

## 입주 방식 스위치 (관리자 화면 `#/admin`)
- `off`: 예전처럼 닉네임만 (기본값. 키티챗/토큰 준비 전까지)
- `password`: 아이디 + 암호만 (Meta 토큰이 아직 없거나 막혔을 때). 되찾기는 안 되고 신고만.
- `comment`: 아이디 + 암호 + 댓글 확인 (목표)

## 사용자가 할 일 (폰)
1. 인스타를 크리에이터 계정으로 바꾸기.
2. 키티챗 Pro 가입, 계정 연결.
3. 키티챗 설정: 키워드 `입주` 포함 댓글 → 모든 게시물 → 버튼 DM → 팔로워: 암호 / 비팔로워: "팔로우하고 버튼 다시 눌러주세요".
4. Cloudflare 대시보드 → Worker `cat-island` → Settings → Variables and Secrets → **Secret** `ADMIN_KEY` 추가 (아무도 모를 긴 글자).
5. 원격 DB 에 0007 적용 (Claude 가 커넥터로 할 수 있음).
6. 사이트 `#/admin` → 관리자 키 → 암호 넣고 방식 `password` 로 시작.
7. Meta 개발자 앱 → 인스타 연결 → 장기 토큰 → `#/admin` 의 "새 토큰 넣기" (채팅에 붙이지 않기) → "지금 댓글 읽기"로 확인 → 방식 `comment`.
- 암호는 퍼질 수 있으니 주 1회 바꾸기(키티챗 DM 문구와 관리자 화면 둘 다).
