# 작업: 인스타 인증 (댓글 코드 + 키티챗 팔로워 암호)

새 채팅에서 이 파일을 먼저 읽고 시작한다. (2026-11-16 결정)

## 결론 (왜 이 방식인가)
- 사용자는 **사업자 등록을 할 수 없다** → Meta 앱 심사(고급 권한) 불가 → 아무 유저의 DM 을 받는 웹훅은 못 쓴다.
- 매니챗 Pro 는 외부 요청(웹훅) + 팔로워 조건이 되지만 **비싸서 제외**.
- **키티챗 Pro ($22/월)** 로 결정. 인스타 계정 2개(고양이섬 + 드럼) 연결 가능.
- 소셜비즈: 게시물·릴스 댓글에서 팔로워 구분 DM 가능, 가격 미확인. 키티챗으로 결정해서 보류.

## 키티챗 상담 확인 내용 (사람 상담원 답변 기준)
- ✅ 인스타 계정 2개 연결 (Pro)
- ✅ 릴스 댓글에도 자동 DM (Starter 부터. AI 상담원이 처음에 "안 된다"고 했다가 사람이 정정)
- ✅ 팔로워 여부에 따라 다른 버튼 DM (Starter 부터)
- ✅ 댓글에 특정 키워드가 포함될 때만 DM 발송
- ✅ 모든 게시물에 한 번에 적용
- ✅ DM 무제한 (Starter 부터)
- ❌ **외부 주소로 API/웹훅을 부르는 기능 없음** → 키티챗은 우리 서버에 "누가 보냈는지"를 알려줄 수 없다.
- 동작 방식: 기본 메시지는 댓글 단 모두에게 가고, 버튼을 누를 때의 팔로우 상태에 따라 후속 메시지가 달라진다.
- 미확인(가입 후 직접 시험): 팔로우 후 버튼을 다시 누르면 팔로워 메시지가 나오는지 / 문구 수정이 전체에 바로 반영되는지 / 같은 사람이 여러 번 댓글 달면 DM 이 매번 가는지.

## 역할 나누기
| 확인할 것 | 누가 | 방법 |
|---|---|---|
| 이 사람이 진짜 그 아이디 주인인가 | **우리 서버** | 내 게시물 댓글을 Meta API 로 5분마다 읽어서 코드와 댓글 쓴 아이디를 맞춘다 |
| 이 사람이 팔로워인가 | **키티챗** | 팔로워에게만 보이는 버튼 DM 안에 "팔로워 암호"(주 1회 교체)를 넣는다 |

hanchae-maeul.pages.dev 의 "댓글로 남겨도 됩니다, 확인까지 5분쯤" 이 같은 방식(댓글 주기 확인)이다.

## 유저 흐름
1. 사이트에서 입주 코드 `집-XXXX` 받기 (15분 유효, 화면은 몇 초마다 상태 확인).
2. 지정 게시물/릴스에 그 코드를 댓글로 남기기.
3. 서버(Cron 5분)가 댓글을 읽고 코드 → 댓글 쓴 아이디 확인 → 아이디 인증(`verified`).
4. 키티챗이 `집-` 키워드 댓글에 버튼 DM 발송 → 팔로워면 "팔로워 암호: ○○○" (또는 암호가 든 사이트 링크).
5. 사이트에 암호 입력(또는 링크 클릭) → 팔로워 확인 → 입주 완료.
- 암호는 퍼질 수 있으니 주 1회 교체(관리자 화면). 고양이 게임 수준에선 충분하다고 판단.

## Meta 개발자 앱 (사업자 불필요할 것으로 판단, 실제로 확인 필요)
- developers.facebook.com = 인스타에 "우리 서버가 내 계정 댓글을 읽어도 된다"고 허락(출입증)하는 곳. 폰 앱이 아니라 신청서 이름.
- **개발 모드 그대로** 사용. 심사·사업자 인증 신청하지 않는다. 개발 모드에서도 앱 관리자 본인 계정의 데이터(내 게시물 댓글)는 읽을 수 있다(Instagram API with Instagram Login, 표준 권한: instagram_business_basic, instagram_business_manage_comments).
- 인스타는 크리에이터 계정(무료)이면 된다.
- 받은 토큰은 채팅에 붙이지 말고 `wrangler secret put` 으로 넣는다(사용자에게 폰에서 쉬운 방법 안내). 장기 토큰은 60일 만료 → 자동 갱신 로직 필요.
- 막히면(사업자 요구 등): 댓글 확인 없이 "아이디 + 팔로워 암호"만으로 입주하는 느슨한 모드로 바꿀 수 있게 설정값 하나로 전환되게 만든다.

## 사용자에게 줄 안내 (폰에서 따라 하기 쉽게, 한국어)
1. 인스타를 크리에이터 계정으로 바꾸기.
2. 키티챗 Pro 가입, 계정 2개 연결.
3. 키티챗 설정: 키워드 `집-` 포함 댓글 → 모든 게시물 → 버튼 DM → 팔로워: 암호(+링크) / 비팔로워: "팔로우하고 버튼 다시 눌러주세요".
4. Meta 개발자 앱 만들기 → 인스타 연결 → 토큰 받아서 안전하게 넣기. 막히면 화면 캡처 보내기.
