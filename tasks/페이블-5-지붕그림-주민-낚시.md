# Fable 작업 5 — 지붕 그림, 주민(NPC) 고양이, 낚시 모습 (제안, 2026-11-15)

사용자 요청: "집 꾸미기에 지붕 직접 그리기, 퀘스트/미니게임으로 화분 같은 소품 얻기, 맵의 주민 집에 가서 뭔가 하기, 낚시."
앱/서버/DB(Opus)는 먼저 다 붙여 두었다(README.md "2026-11-15 꾸미기, 츄르, 퀘스트, 미니게임"). 지금은 씬에 맞는 함수가 없어서
지붕 그림은 3D 에 안 보이고, 주민은 다른 유저 고양이(`setRemotePlayers`)에 섞어 그리고 있다. 아래 함수가 생기면 앱이 바로 그쪽을 쓴다.
먼저 CLAUDE.md 와 README-scene.md 를 읽는다. 기존 함수는 바꾸지 않고 새 함수만 더한다.

## 1. 지붕 그림 (가장 급함)
- 새 함수: `setRoofArt(items: Array<{ houseNo: number; drawingId: string }>)`
  - **지금 보여 줄 지붕 그림 전체**(가까운 집 것만). 목록에서 빠진 집은 그림을 뗀다. `setDrawings` 와 같은 방식.
  - 그림 내용은 이미 `setDrawings` 로 넘긴 것을 쓴다(앱이 지붕 그림도 `setDrawings` 목록에 넣어서 같이 보낸다).
  - 그림이 아직 안 왔으면 지붕 색만 보인다.
- 모양 제안: 지붕 앞면(대문 쪽 경사면)에 32x32 그림을 붙인다. 지붕 색은 그대로 두고 그림 둘레로 보이게(그림이 지붕 전체를 덮지 않게). 픽셀이 또렷하게(가까운 이웃 필터).
- 성능: 그림 붙은 지붕은 가까운 집만(예: 32채). 먼 집은 지붕 색만.
- 앱 쪽은 이미 `art.ts` 에서 `typeof scene.setRoofArt === 'function'` 이면 부른다. 함수 이름과 인자를 이대로 해 주면 앱은 고칠 것이 없다.

## 2. 주민(NPC) 고양이
- 지금 앱이 동네 가운데마다 주민 하나(광장: 잡화점/오락실, 연못: 낚시꾼, 큰 나무: 정원사)와 주민 집(빈 집) 안 고양이를 `setRemotePlayers` 에 섞어서 그린다. 그래서 이름표가 `@잡화점 보리` 처럼 `@` 가 붙는다.
- 새 함수 제안: `setNpcs(npcs: Array<{ id: string; name: string; x: number; z: number; rotY: number; cat: CatLook; role?: string }>)`
  - 다른 유저와 같은 고양이 모양. 이름표는 `@` 없이, 다른 색(예: 연두)으로. 역할 표시(작은 모자, 앞치마, 낚싯대, 물뿌리개)가 있으면 좋다.
  - 집 안에 있을 때는 방 좌표로 그린다(`setRemotePlayers` 와 같은 규칙).
  - 주민은 제자리에 앉아 있거나 가끔 둘레를 조금 걷는다(위치는 앱이 준 자리 근처).
- (선택) `onNpcTap(cb(id))`: 주민을 누르면 알림. 지금 앱은 가까이 가면 "말 걸기" 버튼을 띄운다.
- 앱이 쓰는 주민 자리 계산은 `src/app/play/npcs.ts` 에 있다. 주민이 나무/벤치와 겹쳐 보이면 알려 주거나, 씬이 좋은 자리를 내보내 줘도 된다(예: `npcSpot(neighborhood)`).

## 3. 낚시
- 앱은 연못 가운데에서 `POND_R + 2.3` 안이면 "낚시하기" 버튼을 띄우고, 2D 미니게임 판을 연다. `POND_R` 값(4.3)을 앱이 따로 들고 있으니, 씬이 `POND_R` 를 공개하거나 `fishingSpotAt(x, z): boolean` 를 내보내 주면 좋다.
- 1구역 항구(부두)에서도 낚시할 수 있게 하고 싶다. 부두 끝 근처인지 알려 주는 함수가 있으면 붙이겠다.
- 새 함수 제안: `setFishing(state: 'cast' | 'wait' | 'bite' | 'reel' | 'caught' | null)` → 내 고양이가 연못을 보고 앉아 낚싯대를 드리운 모습. 찌가 물에 떠 있고, bite 에서 찌가 들어가고, caught 에서 물고기를 들어 올린다. null 이면 원래대로.
  - 낚시 중에는 조이스틱을 막아도 된다(앱이 미니게임 판으로 화면을 덮고 있다).
